## Specs

- **S1**: Build a native Rust local application (`vamos rust nativo`) named `truesight-dota` at `/data/Projects/truesight-dota` following a scalable Hexagonal Architecture (`sigamos una arquitectura hexagonal escalable y consideremos el uso de mi skill ~/.pi/agent/skills/rust-architect/SKILL.md`).
- **S2**: Implement a real-time 5v5 draft analysis matrix (`un tabla 5v5 donde muestra los picks y en verde sus probabilidades positivas y de rojo las negativas, lo que resulta en un analisis matematico en vivo de las elecciones de heroe`).
- **S3**: Implement hero suggestions ranked from current draft picks by contrasting base meta hero winrates against match picks (`heroes sugeridos a partir de los picks asi tambien este supongo ya tiene el winrate de los heores meta que luego se contrastan contra los picks de la partida para entregar la mejor probabilidad`).
- **S4**: Follow the Phase 1 sequence (`esa secuencia me parece correcta`): mathematical engine + interactive quick-pick selector + local GSI state listener + STRATZ/OpenDota data adapter, with clean port boundaries for Phase 2 screen capture.
- **S5**: Create project architecture documentation in `docs/` and a project `README.md` (`creemos documentacion con la architecura del proyecto en docs/ tras terminar de definir o tambien creemos el readme`).
- **S6**: Synchronize the complete 127-hero catalog and real player comfort history (`127255741`) into a local snapshot adapter (`SeededMetaRepository`) and add a native `eframe`/`egui` desktop GUI alongside the CLI/TUI (`ok procede`).
- **S7**: Upgrade and pin the Rust toolchain to `1.99.1`, package a release desktop executable (`~/.local/bin/truesight-dota` + `~/.local/share/applications/truesight-dota.desktop`), and install the Dota 2 GSI integration config (`por que no usamos la ultima version 1.99.1? cual seria el sifuiente paso, deberiamos tener un ejecutable de escritorio` / `1. autorizo actualizacion 2. procedamos`).
- **S8**: Fix manual testing findings (`solo veo 0% en todos los calculos`, `los suggest deberia ser otra seccion`, `la eleccion de cada herore por slot no permite escoger todos lo heores de manera independiente. se tiene que pickear desde el panel de suggetsed pick`, `revisa la imagen para notar otras inconsistencias y corregirlo`): embed all 15,966 (`127x127`) empirical OpenDota matchup & synergy pairs, add independent 127-hero dropdown selectors per slot (`A1..A5`, `E1..E5`), move `Suggested Heroes` into its own dedicated bottom section, fix neutral `0.00%` coloring, and evaluate `Draft Gain` against the vacated target slot.
- **S9**: Fix the 5 statistical inconsistencies identified in the draft audit (`analicemos este es otro draft que ya parece mejor calibrado. identifiquemos inconsistencias en nuestro motor estadistico` / `procede a aplicar y luego realiza una simulacion de draft para evaluar si los resultados ahora don estadistica y matematicamente consistentes`): separate `Avg Counter` and `Avg Synergy` per row, double-center the 127x127 synergy matrix to zero mean with strict antisymmetry $\Delta C(A, B) = -\Delta C(B, A)$, assign authoritative modern Dota 2 Pos 1–5 roles per hero, remove conflicting pair overrides, and unify `Projected Win%` with the header `ALLIES WIN PROBABILITY`.
- **S10**: Fix the 3 bracket & UX findings (`el motor probabilistico no muestra el cambio tras cambiar de bracket`, `cuando seleccionas un heroe, no puedes escribir tienes que dejar pulsado el click y escribir para poder seleccionar un heore`, `los brackets no deberian aparecer por cada uno en lugar de tenerlos en pares?` / `procedamos y utiliza tdd para la ejecucion. lo hiciste antes? tambien verifica que todos los datos estadisticos de esta simulacion son correctos`): split `Bracket` into all 8 individual Dota 2 medals (`Herald`..`Immortal`), dynamically scale counter & synergy matrices per medal while preserving strict antisymmetry/symmetry, and replace `ComboBox` with an auto-focused click-to-type slot picker panel.
- **S11**: Enhance the statistical engine with 7-day patch momentum (`pub_pick_trend`/`pub_win_trend`), exponential recency decay on personal comfort (`last_played`), structural team composition balance (`attack_type` Melee/Ranged + `Disabler`/`Initiator` tags), and explicit Allied vs Enemy synergy breakdown (`luego dale una lectura al motor y veamos si existen mejoras por hacer con los datos que obtenemos de nuestras fuentes estadisticas` / `si, implementemoslo`).
- **S12**: Implement local database cache and automatic/manual synchronization (`necesitamos una frecuencia de actualizacion de nuestra base de datos, podria ser una vez al dia o ver cual es la frecuencia de actualizacion de la fuente` / `si, implementemoslo`): 24h TTL for OpenDota `heroStats`, 1h TTL for player profile `127255741`, `[Sync DB]` button + freshness badge in the GUI header, `sync` CLI command, and ASCII glyph fix (`[v]`) on slot buttons.
- **S13**: Formally update the engineering task plan in `docs/`, `docs/architecture.md`, and `README.md` (`planifiquemoslo bien y actualicemos el plan de tareas formalmente tambien en docs y actualizar el readme`).
- **S14**: Fix Personal Comfort inflation on inactive/low-recency heroes (`me parece extraÑo que mi confort para juggernaut y antimage sea tan alto comparado con otros heores jugados recientes y estos no los juego hace mucho. no veo aqui la meyora implementada o algo no se esta considerando` / `autorizo y tambien actualicemos los docs`): replace single-timestamp lifetime decay (`last_played` over `/heroes`) with per-match exponentially time-weighted effective games & wins ($\tau = 75\text{d}$) from `/api/players/127255741/matches` plus an active-volume mastery bonus $\ln(1 + G_{\text{eff}})$, integrate `player_comfort_edge` for `draft.target_role` directly into `evaluate_draft_5v5`, and update `docs/` and `README.md`.
- **S15**: Add `AGENTS.md` with mandatory implementation and TDD testing policies, create the product domain skill (`skills/truesight-dota-domain/SKILL.md`) and bundle the Rust architecture skill (`skills/rust-architect/SKILL.md`) indexed in `.atl/skill-registry.md`, and add the `Apache-2.0` `LICENSE` file for open-source publication (`el proyecto necesita un agents.md con la politica importante de implementacion y testing y cerremos con una skill de dominio del producto finalmente terminaremos publicando el proyeto open source con licencia apache 2.0 creo que es correcto para esto` / `tambien lleva a este drectorio la skill de rust`).
